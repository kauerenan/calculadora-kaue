# 🧮 Calculadora Kaue Renan

Minha primeira calculadora feita com **HTML, CSS e JavaScript**.  
Permite realizar operações básicas: ➕ adição, ➖ subtração, ✖️ multiplicação e ➗ divisão.  
Inclui botão de limpar e interface estilizada.

## 🚀 Como usar
1. Abra o arquivo `calculadora.html` no navegador.
2. Digite dois números.
3. Clique na operação desejada.
4. Veja o resultado aparecer na tela.

## 📂 Estrutura do projeto
- `calculadora.html` → estrutura da página
- `calculadora.css` → estilos visuais
- `calculadora.js` → lógica da calculadora

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
